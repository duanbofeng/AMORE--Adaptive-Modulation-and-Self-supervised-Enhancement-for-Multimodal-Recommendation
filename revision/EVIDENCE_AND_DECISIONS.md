# 原始模型和已有证据

## 来源锁定

`old_model/src/models/gume.py` 是原始 AMORE 的实际网络；同目录 `amore.py` 是包装。`src/models/archive/amore_original.py` 与前者逐字节一致，SHA256 为 `8209d878dbe065155767367fc14a7baee05b28b87b197ea7e268c7a58e89edb6`。文件、原稿、审稿意见、21 条结果行及 9 个日志的来源记录见 `evidence/provenance.json`。

旧 `main.py` 默认选择 gume，它和显式 amore 使用不同 YAML。日志文件名叫 GUME 不足以确认模型身份，应同时查看路径、完整配置、是否包含亲和力字段、源码版本。旧实验选择协议可能不同，不能直接与新协议混合计算显著性。

## 已有 Baby 验证结果

| 版本 | Recall@20 | NDCG@20 | 证据 |
|---|---:|---:|---|
| 原始 AMORE `amore_original` | 0.102092 | 0.044234 | 31_original_baby，原始 result/history，seed 999 |
| 保守修复 `amore_fixed` | 0.101843 | 0.043973 | 同批次 |
| compact | 0.097151 | 0.042574 | 同批次 |
| compact 无亲和力 | 0.098237 | 0.043029 | 同批次 |
| GUME | 0.101644 | 0.044344 | 11_fusion_baby，只有报告表，不能认定为严格匹配对照 |

另有 01_core_baby 中的 slim `amore_base` 0.089952、GUME 0.101545。这个差距主要比较的是不同主干，不能归因于原始亲和力。11_fusion 的 Ego/SG 组合约 0.1011–0.1016，没有表现出稳定全面增益。

这些是历史验证结果，不是修稿后的最终测试结果；均不足以支持“稳定提升”。compact 的下降提示大幅删除辅助结构存在风险，因此先保留原始完整主干做可归因消融。本轮不继续向论文叠加 SG 或 Ego 新模块，也不将失败尝试删除或包装成贡献。

## 代码与论文的实质差异

| 原稿表述/实现 | 修订处理 |
|---|---|
| 逐边过滤消息 | 实际先算边亲和力，再按物品池化，调制所有接收者共享的物品初始嵌入；如实描述 |
| 保持 ID 路径不变 | 只保持图连接，物品初始 ID 表示会改变；删除数值不变的声称 |
| Gaussian 对齐 | 全局标量均值和总体方差的绝对差；不等于高斯散度，也不能证明语义对应 |
| dimension-weighted BPR | 原始默认关闭；修复版使用与测试相同的标准点积评分 |
| 残差增强 alpha、fine-grained weight | 原前向最终未使用相应增强量；不把死代码当成贡献或敏感性变量 |
| 全模型 L2 | 实际是采样最终表示和扩展正物品表示的惩罚 |
| 多个重复身份作为负例 | 修复为唯一身份 InfoNCE；明确作为修复与原始版分别报告 |
| 固定 batch 分母 | 修复为实际 batch 大小 |
| 两张 extended user embedding 表 | 原始未使用；初始化后删除，保留其他共有参数初始化随机序列 |
| 11/12 基线、引述性能混表 | 主表仅列统一复现方法，缺失方法明确标记；不提前固定“12 个” |

## 模型选择决定

当前模型是修稿用受控实现，不是已经得到更高分的新模型。优先级：来源确认 → 共同主干 2×2 → 常数/打乱先验 → 单损失 → 同预算调参 → 冻结测试。若无稳定增益，保留负结果并下调贡献陈述。是否改名、去掉亲和力、采用单支都由验证证据决定，而不是本地 CPU 单元测试决定。
